“全自动大物实验”网站起源于一次青涩的尝试：能不能用把实验报告中复杂的不确定度计算封装成简单易用的GUI页面？在ChatGPT的指导下，我磕磕绊绊地用React实现了计算模块的原型。后来我发现，很多人都在被手搓实验报告所困扰，一个想法萌发出来———或许可以增加自动生成报告的功能、然后提供给大家使用。之后的代码几乎完全由vibe coding生成，并且在别的伙伴的贡献下，我们的功能越来越完善。很高兴看到，网站的用户越来越多，帮到了更多的人。
或许ai agent完全可以完成相同的任务，但是复用现有模板可以保证快速、稳定地产出高分报告，所以这个项目仍有一些意义在吧。

技术栈

网址：https://lab.tongji.sh
项目前端读取数据，后端自动计算不确定度、画图、填入模板并生成.pdf格式的报告。资料页面还收集了课程安排、评分细则、常用平台等信息。

  • 前端:React,shadcn/ui,Tailwind CSS,vite
  • 后端:go,SQLite,docker
  • 配合typst进行报告生成

网站使用cookie识别用户，同一cookie可以下载之前的报告。
此外，还有DSH skill版本可以调用上述网址的MCP server从而使用。
项目源码已经于Github开源。

git clone https://github.com/ahajerry/tj-phyExpReport

功能

数据读入


支持手动输入数据、上传.xlsx或.csv格式的原始数据（具体支持情况根据学校实验平台的不同实验输出情况而定）、传入json格式的数据。
其中，json格式主要是为了ai识别读数设计。可以把数据单图片传给ai，使用给出的提示词，让ai识别文字并输出报告所需要的数字。

科学计算

自动完成不确定度计算。
$$ u_c(y)=\sqrt{\sum_{i=1}^{N}\left(\frac{\partial f}{\partial x_i}\right)^2 u^2(x_i)} $$
对于A类不确定度的计算以及各物理量的不确定度传递，一直是完成报告时最繁琐的部分。现在，使用本项目点击一下即可完成计算————可以完全在手机上进行以至于在实验课下课前就能把计算结果誊抄到数据单上。

作图

调用typst的作图模块（在之前的版本中，通过latex tikz包实现），绘制数据点并进行拟合。对于手搓而言，无论是用纸笔作图还是手写代码生成都尤为繁琐，而使用ai agent绘图需要下载matplotlib等包，或许也有一些复杂。

填充细节
模板中内置了从实验课本和学习通上摘录的文字资料以及截图。支持在生成报告的末尾插入原始数据图片。
